# Welcome to GenAIScript

GenAIScript is a powerful tool for creating and running AI-powered scripts.

## Features

- **Easy to use**: Simple JavaScript-based scripting
- **Powerful**: Integrate with various LLM providers
- **Flexible**: Support for multiple file formats

## Getting Started

To get started with GenAIScript:

1. Install the CLI tool
2. Create your first script
3. Run it with your preferred model

### Code Example

Here's a simple example:

```javascript
script({
    title: "Hello World",
    description: "A simple greeting script"
})

$`Hello, world! Please respond with a greeting.`
```
