Support des outils Agentic

27 août 2024
Peli
GenAIScript developer

Agentic est une bibliothèque TypeScript conçue pour simplifier l’intégration d’outils d’IA, prenant en charge à la fois les scripts locaux et les flux de travail basés sur LLM. Elle se connecte de manière transparente à des API comme Bing, Wolfram Alpha ou Wikipedia, améliorant ainsi l’efficacité des tests et du débogage. Si vous travaillez avec des outils d’automatisation intelligente, Agentic offre une base flexible sur laquelle construire.
