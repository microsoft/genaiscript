Les diagrammes Mermaid sont une méthode populaire pour créer des diagrammes en markdown. Ils sont utilisés dans de nombreux projets, y compris dans GitHub Markdown. Étant donné qu’il existe de nombreux exemples de diagrammes mermaid dans la nature,

Il n’est pas surprenant que les LLM soient assez bons pour les générer.

Diagrammes Mermaid dans Markdown

Section intitulée « Diagrammes Mermaid dans Markdown »

Mermaid prend en charge plusieurs types de diagrammes ainsi que plusieurs options pour contrôler l’apparence des nœuds et des arêtes. Vous pouvez essayer différents diagrammes dans le aire de jeux Mermaid

Erreurs de syntaxe

Section intitulée « Erreurs de syntaxe »

Un problème avec Mermaid est que… la syntaxe a de l’importance et les LLM se trompent parfois. Introduisons une erreur de syntaxe dans l’exemple ci-dessus.

Maintenant, Mermaid ne parvient pas à analyser et le diagramme n’est pas rendu :

Dans la plupart des cas, le LLM est capable de corriger l’erreur de syntaxe et de générer un diagramme valide en utilisant le message d’erreur.

Réparation automatique

Section intitulée « Réparation automatique »

Nous avons ajouté un “réparateur” dans l’invite système system.diagrams. Le réparateur recherche les blocs de code mermaid dans la sortie et tente de les analyser. Si le diagramme présente des erreurs d’analyse, le réparateur ajoute un message au chat pour les corriger.

Voici une trace d’un script simple qui génère un diagramme à partir de n’importe quel code.

Nous exécutons la cli avec le script mermaid.genai.mjs et le fichier runpromptcontext.ts.

Le réparateur entre en jeu et répond à l’assistant avec un message pour corriger l’erreur. La conversation complète du chat est renvoyée au LLM, y compris le message d’erreur.
