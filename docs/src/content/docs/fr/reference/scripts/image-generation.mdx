GenAIScript prend en charge les fournisseurs de modèles de langage (LLM) avec des [API de génération d'images compatibles avec OpenAI](https://platform.openai.com/docs/guides/images).

## Fournisseurs supportés

Vous devrez configurer un fournisseur de LLM prenant en charge la génération d'images.

* [OpenAI](../../../reference/configuration/openai/)
* [Azure OpenAI](../../../reference/configuration/azure-openai/)
* [Azure AI Foundry](../../../reference/configuration/azure-ai-foundry/)

## Générer une image

Le script principal (top-level) ne peut pas être configuré pour générer une image pour l'instant ; cela doit être fait via un appel à la fonction `generateImage`.

`generateImage` prend une commande (prompt) et retourne une URL d'image ainsi qu'une commande révisée (optionnelle).

```js "generateImage" wrap
const { image, revisedPrompt } = await generateImage(
    `a cute cat. only one. photographic, high details. 4k resolution.`
)
```

L'objet `image` est un fichier image qui peut être utilisé pour d'autres traitements.

```js
env.output.image(image.filename)
```

## Édition et variations d'images

Pour les modèles qui le supportent (comme `gpt-image-1`), vous pouvez aussi fournir des images d'entrée pour l'édition ou la création de variations :

### Éditer des images existantes

```js "generateImage" wrap
const robotsImage = await workspace.readFile("src/robots.jpg")

const { image, revisedPrompt } = await generateImage(
    "Transformer cette image en une bannière moderne avec un arrière-plan dégradé bleu",
    robotsImage,
    {
        model: "openai:gpt-image-1",
        operation: "edit",
        size: "1792x1024",
        quality: "high"
    }
)
```

### Créer des variations d'images

```js "generateImage" wrap
const robotsImage = await workspace.readFile("src/robots.jpg")

const { image, revisedPrompt } = await generateImage(
    "Créer une variation artistique de cette image",
    robotsImage,
    {
        model: "openai:gpt-image-1",
        operation: "variations",
        size: "1024x1024",
        quality: "high"
    }
)
```

### Entrées d'images multiples

Vous pouvez fournir plusieurs images en entrée :

```js "generateImage" wrap
const image1 = await workspace.readFile("src/image1.jpg")
const image2 = await workspace.readFile("src/image2.jpg")

const { image, revisedPrompt } = await generateImage(
    "Combiner ces images en un collage créatif",
    [image1, image2],
    {
        model: "openai:gpt-image-1",
        operation: "edit",
        size: "1024x1024",
        quality: "high"
    }
)
```

### Détection automatique d'opération

Si vous fournissez des images sans spécifier d'opération, le système utilisera automatiquement le mode "edit" :

```js "generateImage" wrap
const robotsImage = await workspace.readFile("src/robots.jpg")

const { image, revisedPrompt } = await generateImage(
    "Rendre cette image plus colorée",
    robotsImage,
    {
        model: "openai:gpt-image-1",
        size: "1024x1024"
    }
)
```
