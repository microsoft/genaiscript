GenAIScript provides various utilities to retrieve content and augment the prompt.
This technique is typically referred to as **RAG** (Retrieval-Augmentation-Generation) in the literature.

## Agentic Search

The `retrieval.agenticSearch` provides intelligent search that combines multiple search strategies with AI-powered query rewriting for optimal results.

```js
const results = await retrieval.agenticSearch("machine learning", env.files, {
    topK: 10,
    queryVariations: 3,
    combinationStrategy: "weighted",
    includeWebSearch: true,
    includeVectorSearch: true,
    includeFuzzSearch: true,
    searchWeights: {
        vector: 0.5,
        web: 0.3,
        fuzzy: 0.2
    }
})
def("SEARCH_RESULTS", results)
```

### Features

- **Query Rewriting**: Automatically generates multiple query variations using AI for improved search coverage
- **Multi-Strategy Search**: Combines vector search, web search, and fuzzy search in parallel
- **Smart Result Fusion**: Uses advanced algorithms (weighted, RRF, simple) to combine and rank results
- **Configurable**: Full control over search types, weights, and result filtering

### Options

- `topK`: Maximum number of results to return (default: 10)
- `minScore`: Minimum score threshold for results (default: 0)
- `queryVariations`: Number of AI-generated query variations (default: 2)
- `combinationStrategy`: Result combination algorithm - "weighted", "rrf", or "simple" (default: "weighted")
- `includeWebSearch`: Enable web search (default: true)
- `includeVectorSearch`: Enable vector search (default: true)  
- `includeFuzzSearch`: Enable fuzzy search (default: true)
- `searchWeights`: Custom weights for each search type
- `webSearchProvider`: Web search provider - "bing" or "tavily"
- `embeddingsModel`: Model for vector embeddings
- `indexName`: Vector search index name

### Tool Usage

The agentic search is also available as a tool for LLM usage:

```js
system: ["system.retrieval_agentic_search"]
```

This enables the LLM to automatically use agentic search when needed to find relevant information.

## Vector Search

GenAIScript provides various vector database to support embeddings (vector) search.

```js
// index creation
const index = await retrieval.index("animals")
// indexing
await index.insertOrUpdate(env.files)
// search
const res = await index.search("cat dog")
def("RAG", res)
```

- Read more about [vector search](/genaiscript/reference/scripts/vector-search) and how to use it.

## Fuzzy Search

The `retrieve.fuzzSearch` performs a "traditional" fuzzy search to find the most similar documents to the prompt.

```js
const files = await retrieval.fuzzSearch("cat dog", env.files)
```

## Web Search

The `retrieval.webSearch` performs a web search using a search engine API. You will need to provide API keys for the search engine you want to use.

```js
const { webPages } = await retrieval.webSearch("cat dog")
def("RAG", webPages)
```

### Bing

To enable Bing search, configure the `BING_SEARCH_API_KEY` secret in your `.env` file. Learn more about [configuring the Bing Search API](https://www.microsoft.com/en-us/bing/apis/bing-web-search-api).
