The `importCopilotInstructions` runtime helper automatically discovers and imports relevant GitHub Copilot instruction files based on the files being processed.

## Basic Usage

```typescript
import { importCopilotInstructions } from "@genaiscript/runtime"

// Import instructions that apply to current files
const instructions = await importCopilotInstructions(workspace)
if (instructions?.length) {
  $`# Instructions\n${instructions.map(i => i.content).join('\n\n')}\n\n# Task\n...`
}
```

## Features

- Searches `.github/instructions/` and `.github/copilot-instructions.md` by default
- Matches instruction files to selected files using glob patterns from frontmatter `applyTo` field
- Supports general instructions (files without specific patterns)
- Configurable instruction paths, file patterns, and options

## Setting up Copilot Instructions

### 1. Create specific instruction files in `.github/instructions/`

```markdown
---
applyTo: "**/*.ts"
description: "TypeScript coding standards"
---

# TypeScript Guidelines

- Use strict type checking
- Prefer interfaces over type aliases for object shapes
- Document public APIs with JSDoc
```

### 2. Create general instructions in `.github/copilot-instructions.md`

```markdown
# General Coding Standards

- Write clean, readable code
- Add meaningful comments
- Follow existing project conventions
```

## API Reference

### importCopilotInstructions()

```typescript
function importCopilotInstructions(
  workspace: WorkspaceFileSystem,
  options?: CopilotInstructionsOptions
): Promise<CopilotInstruction[]>
```

**Parameters:**
- `workspace` - The workspace file system to read files from
- `options` - Configuration options (optional)

**Returns:** Promise that resolves to an array of relevant copilot instructions that apply to the current env.files

### CopilotInstructionsOptions

```typescript
interface CopilotInstructionsOptions {
  /** Whether to include general copilot instructions file (default: true) */
  includeGeneral?: boolean;
  /** Custom paths to search for instruction files (default: [".github/instructions", ".github"]) */
  instructionPaths?: string[];
  /** Custom patterns to match instruction files (default: ["*.instructions.md", "copilot-instructions.md"]) */
  instructionPatterns?: string[];
}
```

### CopilotInstruction

```typescript
interface CopilotInstruction {
  /** The file path of the instruction file */
  filename: string;
  /** The instruction content */
  content: string;
  /** Parsed frontmatter metadata */
  metadata?: {
    /** File patterns this instruction applies to */
    applyTo?: string | string[];
    /** Description of the instruction */
    description?: string;
    [key: string]: any;
  };
}
```

## Examples

### Code Review with Instructions

```typescript
script({
    title: "Code Review with Copilot Instructions",
    description: "Reviews code using relevant GitHub Copilot instructions",
})

import { importCopilotInstructions } from "@genaiscript/runtime"

const instructions = await importCopilotInstructions(workspace)

if (instructions?.length) {
    $`# Code Review Instructions

${instructions.map(inst => {
    let content = inst.content
    if (inst.metadata?.description) {
        content = `## ${inst.metadata.description}\n\n${content}`
    }
    return content
}).join('\n\n---\n\n')}

# Files to Review

Please review the following files according to the instructions above:`

    def("FILES", env.files, { lineNumbers: true })
} else {
    $`No specific instructions found. Please review the files using general best practices.`
    def("FILES", env.files, { lineNumbers: true })
}
```

### Custom Configuration

```typescript
const instructions = await importCopilotInstructions(workspace, {
    includeGeneral: false, // Skip general instructions
    instructionPaths: [".github/instructions", "docs/coding-standards"], // Custom paths
    instructionPatterns: ["*.guidelines.md", "*.standards.md"] // Custom patterns
})
```

## Pattern Matching

Instruction files use glob patterns in their frontmatter `applyTo` field to specify which files they apply to:

```markdown
---
applyTo: 
  - "**/*.ts"
  - "**/*.tsx"
  - "!**/*.test.ts"
description: "React TypeScript components"
---

# React TypeScript Guidelines
...
```

The helper uses the same glob matching engine as GenAIScript's file selection, supporting:
- `**` for recursive directory matching
- `*` for single-level wildcards
- `!` for exclusion patterns
- Character classes and other minimatch features
