The `importCopilotInstructions` runtime helper automatically discovers and imports relevant GitHub Copilot instruction files based on provided files. The helper automatically adds these instructions as system prompts to the chat generation context.

## Basic Usage

```typescript
import { importCopilotInstructions } from "@genaiscript/runtime"

// Import instructions that apply to specific files and add to context
await importCopilotInstructions(env.files)
// Instructions are now automatically included in the conversation
```

## Custom Context

```typescript
import { importCopilotInstructions } from "@genaiscript/runtime"

// Use with explicit chat generation context
await importCopilotInstructions(env.files, { generator: ctx })
// Instructions are automatically added as system content
```

## Features

The helper automatically searches `.github/instructions/` and `.github/copilot-instructions.md` by default. It matches instruction files to provided files using glob patterns from frontmatter `applyTo` field and supports general instructions for files without specific patterns. The helper provides configurable instruction paths and file patterns with automatic system prompt integration.

## Setting up Copilot Instructions

### 1. Create specific instruction files in `.github/instructions/`

```markdown
---
applyTo: "**/*.ts"
description: "TypeScript coding standards"
---

# TypeScript Guidelines

Use strict type checking, prefer interfaces over type aliases for object shapes, and document public APIs with JSDoc.
```

### 2. Create general instructions in `.github/copilot-instructions.md`

```markdown
# General Coding Standards

Write clean, readable code, add meaningful comments, and follow existing project conventions.
```

## API Reference

### importCopilotInstructions()

**Parameters:**
`files` represents an array of files to match against instruction patterns, while `options` provides configuration options including optional chat generation context.

**Returns:** Promise that resolves when instructions are added to the chat generation context

### Options

The options parameter supports the following configuration:

`includeGeneral` controls whether to include general copilot instructions file (default: true)

`instructionPaths` specifies custom paths to search for instruction files (default: [".github/instructions", ".github"])

`instructionPatterns` defines custom patterns to match instruction files (default: ["*.instructions.md", "copilot-instructions.md"])

Additional options extend ChatGenerationContextOptions for context configuration.

## Examples

### Code Review with Instructions

```typescript
script({
    title: "Code Review with Copilot Instructions",
    description: "Reviews code using relevant GitHub Copilot instructions",
})

import { importCopilotInstructions } from "@genaiscript/runtime"

// Import instructions that apply to files and add to context
await importCopilotInstructions(env.files)

$`Please review the following files:`
def("FILES", env.files, { lineNumbers: true })
```

```typescript
script({
    title: "Code Review with Custom Context",
    description: "Reviews code with automatically integrated GitHub Copilot instructions",

import { importCopilotInstructions } from "@genaiscript/runtime"

// Use with explicit chat generation context
await importCopilotInstructions(env.files, { generator: ctx })

$`Please review the following files:`

```

### Custom Configuration

```typescript
// Custom configuration with automatic system prompt integration
await importCopilotInstructions(env.files, {
    includeGeneral: false, // Skip general instructions
    instructionPaths: [".github/instructions", "docs/coding-standards"], // Custom paths
    instructionPatterns: ["*.guidelines.md", "*.standards.md"] // Custom patterns
})

// Custom configuration with explicit context
await importCopilotInstructions(env.files, {
    generator: ctx,
    includeGeneral: true,
    instructionPaths: [".github/instructions"],
    instructionPatterns: ["*.instructions.md"]
})
```

## Pattern Matching

Instruction files use glob patterns in their frontmatter `applyTo` field to specify which files they apply to:

```markdown
---
applyTo: 
  - "**/*.ts"
  - "**/*.tsx"
  - "!**/*.test.ts"
description: "React TypeScript components"
---

# React TypeScript Guidelines
...
```

The helper uses the same glob matching engine as GenAIScript's file selection, supporting `**` for recursive directory matching, `*` for single-level wildcards, `!` for exclusion patterns, and character classes along with other minimatch features.
